6.3 遷移と戻る操作

  • タブごとにページの積み重ね（URI のリスト）を持つ。同じタブをもう一度押すと積み重ねを空にする
  • 戻る操作は、開いているものの上から順に閉じる：プレーヤー → 設定 → サイドメニュー → ページの積み重ね → ホームのタブ
  • カードを押したとき、アルバム・プレイリスト・アーティストはページを開き、曲は再生する。ユーザーはプロフィールで開く
  • ほかの機器の名前は 2.5 秒続いたときだけ出す（起動直後に前の再生先が一瞬見えるのを防ぐ）

6.4 下の帯（ミニプレーヤーとタブバー）

ミニプレーヤーとタブバーは画面の下にまとめて重ねます。帯の全体が押した判定を受け止め、余白やジェスチャーバーの上を押しても裏の画面に届かないようにしています。タブの当たり判定は上下の余白まで含めます。

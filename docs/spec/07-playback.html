7. 再生と広告

再生の操作、広告の処理、クロスフェード、ギャップレス、音質、Spotify Connect。

7.1 再生の操作

再生の操作はすべて PlayerAPI を呼びます（play・pause・resume・skipToNext・skipToPrevious・seekTo・setShuffle・setRepeat・addToQueue・skipTo・removeFromQueue）。 曲を指定して再生するときは、再生元（アルバム・プレイリスト）と曲の URI を渡します。

7.2 広告の処理

設定の「広告をブロック」がオン（初期値）のときだけ動きます。オフにすると、広告マネージャーを元に戻し、広告の処理もやめます。

流れ

  1. 広告マネージャーの停止：AdManagers.audio と inStreamApi を止める（ad.manager.disabled）。ページの読み込み直しや更新のあとにも、何度でも適用できる
  2. 見張り：0.3 秒ごとに再生中の項目を調べ、広告かどうかを判定する（isAd）。広告の切り替えでは update イベントが来ないことがあるため、イベントとは別にタイマーで見る
  3. 見つけたら：ad.detected を記録し、音声要素の音量を 0.001 にする（ad.mute.applied）。muted にはしない（止めると先へ進めなくなる）
  4. 16 倍速：playbackRate = 16（だめなら 4）。Web Player が速度を戻してくるので付け直す（ad.speed.applied、記録は広告 1 本につき 1 回）
  5. スキップ：広告の区切りごとに 1 回だけ試す（ad.skip.request → accepted / rejected）
  6. 終わったら：音量と速度を戻す（ad.mute.restored）。その後 15 秒は、音量が下がったままになっていないか見張る（ad.volume.fixed）
  7. 保険：ミュートから 75 秒たっても広告のままなら、音量を戻す（ad.mute.failsafe）

やらないこと（試してやめたこと）

方法やめた理由
広告の音声の通信を止める再生が止まって進まなくなった
広告の最後までシークする再生が止まった
Worker で通信を書き換える不安定で、ほかの機能に影響した

7.3 クロスフェード

  • 設定で 1〜12 秒（0 はオフ）。crossfade(sec) でページに伝える
  • 曲の始めと終わりの、それぞれ設定の半分の時間で音量を変える。変え方はサイン曲線（耳に自然な変化）
  • 音量 = 元の音量 × sin(x × π / 2)。x は「始めからの時間 ÷ 半分」と「終わりまでの時間 ÷ 半分」の小さいほう（0〜1）
  • 広告の間はクロスフェードしない。元の音量は 0.01 以上として覚える（広告のミュートの値を覚えないため）
  • クロスフェード中は、曲の切り替えの無音をなくす処理（ギャップの見張り）も動かす

7.4 ギャップレス再生

次の曲を早めに先読みさせ（_preloadUpcomingTrack）、曲の終わりの無音を飛ばして続けて再生します。広告の間と曲の終わり付近の扱いは、広告の処理と食い違わないようにしています。

7.5 音質

設定値表示説明
auto自動通信状況に合わせる（初期値）
low低音質通信量を抑える
normal標準通信量を少し抑える
high高音質AAC 128 kbps（無料プランの Web Player の上限）
very_high最高音質AAC 256 kbps（Premium のみ。選べない表示）

Wi-Fi 用（quality）とモバイル用（quality.cell）を別に持ち、通信が変わると切り替えます。いまの音質は bitrate() で確かめられます。

7.6 Spotify Connect

  • 機器の一覧と再生中の機器は、polyfill.js が connect-state の通信から覚えたクラスタから作る
  • 機器の切り替え（transfer）とほかの機器への再生コマンドは、WebView ではなく端末から送る（ConnectRelay）。WebView が付ける X-Requested-With で拒否されるため
  • 送り直してよいのは、Spotify のドメインの connect-state/v1 と track-playback/v1 で、GET・POST・PUT・DELETE だけ。Cookie・User-Agent・X-Requested-With は付けない
  • スマホのスピーカーと Bluetooth の切り替えは Android の出力の切り替え画面を開く

3. ディレクトリ構成

リポジトリのファイル構成と、各ファイルの役割。

3.1 全体

spotfy/
├── .github/
│   └── workflows/
│       └── ci.yml                 # CI（構文チェック・ビルド・スモークテスト）
├── app/
│   ├── build.gradle.kts           # アプリのビルド設定（VERSION から versionCode を計算）
│   ├── proguard-rules.pro         # R8（難読化・縮小）の設定
│   └── src/main/
│       ├── AndroidManifest.xml    # 権限・Activity・Service・FileProvider
│       ├── assets/
│       │   ├── bridge.js          # ページ側のブリッジ（読み込み完了後に注入）
│       │   └── polyfill.js        # 読み込み開始時に入る下支え
│       ├── java/com/ninjin/spotifyweb/
│       │   ├── MainActivity.kt    # ホスト（WebView・通信・通知・設定）
│       │   ├── Bridge.kt          # アプリ側のブリッジとデータ型
│       │   ├── AppHost.kt         # 画面から使う端末側の機能（interface）
│       │   ├── NativeApp.kt       # 画面のルート・タブ・サイドメニュー
│       │   ├── HomeScreen.kt      # ホーム
│       │   ├── Screens.kt         # ページ・検索・ライブラリ
│       │   ├── Player.kt          # ミニ／全画面プレーヤー・歌詞
│       │   ├── Sheets.kt          # メニュー・デバイスのシート
│       │   ├── Extras.kt          # キュー・タイマー・作成・プロフィール
│       │   ├── DrawerScreens.kt   # 最近・新着
│       │   ├── SettingsScreen.kt  # 設定
│       │   ├── UpdateUi.kt        # アップデートの表示
│       │   ├── AboutScreen.kt     # このアプリについて
│       │   ├── Components.kt      # 共通部品（読み込み中など）
│       │   ├── Theme.kt           # 色・アクセント・AMOLED
│       │   ├── I18n.kt            # 日本語／英語・言語の設定
│       │   ├── Updater.kt         # アプリ内アップデート
│       │   ├── DebugLog.kt        # デバッグログ
│       │   ├── ConnectRelay.kt    # Connect の通信の送り直し
│       │   ├── SpotifyWebView.kt  # WebView の設定（UA・Client Hints）
│       │   ├── AwakeWebView.kt    # 裏でも止まらない WebView
│       │   ├── MediaControls.kt   # メディア通知・MediaSession
│       │   ├── PlaybackService.kt # バックグラウンド再生のサービス
│       │   └── WebViewMissingActivity.kt # WebView が無いときの案内
│       └── res/
│           ├── drawable/          # アイコン（イコライザー）・通知アイコン
│           ├── mipmap-anydpi-v26/ # アダプティブアイコン
│           ├── values/            # 文字列・色・テーマ
│           ├── values-v31/        # Android 12 以降のテーマ
│           └── xml/
│               ├── locales_config.xml  # アプリの言語（ja / en）
│               └── update_paths.xml    # 更新用 APK の置き場（FileProvider）
├── docs/
│   ├── icon.png                   # README のアイコン
│   └── spec/                      # この仕様書
├── scripts/
│   ├── release.sh                 # リリース（ビルド・タグ・GitHub Releases）
│   └── smoke-test.sh              # エミュレーターでの起動まわりの確認
├── build.gradle.kts               # ルートのビルド設定（プラグインの版）
├── settings.gradle.kts
├── gradle.properties
├── VERSION                        # 版の番号（唯一の置き場）
├── CHANGELOG.md                   # 変更履歴（リリースノートの元）
├── README.md / README.en.md       # 説明（日本語／英語）
└── LICENSE                        # MIT

3.2 Kotlin のファイル

ファイル主な中身
MainActivity.ktWebView の生成、WebViewClient（読み込み・エラー・プロセス停止）、onPageMessage、AppHost の実装、通知・サービス・音声出力・通信状態の監視
Bridge.ktcall()、onMessage()、データ型（Card・Shelf・Track・Page・HomeFeed・PlayerState）、キャッシュ（ホーム・ライブラリ・ページ 40 件）
AppHost.kt設定の読み書き、音質、共有、出力の切り替え、デバッグログの共有、ログアウト、Updater
NativeApp.ktタブ（ホーム・検索・ライブラリ）、ページの積み重ね、各シートの表示状態、サイドメニュー、タブバー
HomeScreen.ktHomeScreen・Chips・Shortcuts・FeedCard・ShelfRow
Screens.ktPageScreen・SearchScreen・GenreTile・SearchTyping・LibraryScreen
Player.ktMiniPlayer・FullPlayer・PlayerMain・PlayerExtras・LyricsScreen
Sheets.ktMenuSheet（曲・アルバムなどのメニュー）・DevicesSheet
Extras.ktQueueSheet・SleepTimerSheet・CreateSheet・ProfileScreen・FollowListScreen・EditProfileSheet
DrawerScreens.ktWhatsNewScreen・RecentsScreen
SettingsScreen.kt設定のページ（アカウント・表示・再生・音質・言語）と共通の行（SettingRow・SwitchRow・RadioRow）
UpdateUi.ktUpdateRow（設定の行）・UpdateDialog（お知らせ）
AboutScreen.ktAboutPage（版・作者のクレジット・リンク・注意書き）
Updater.kt状態（Idle〜Failed）、確認（API → リリースページ）、ダウンロード、インストール
I18n.kttr(ja, en)・isJapanese・AppLanguage
DebugLog.kt記録（最大 800 行）、logcat への出力、通信の記録

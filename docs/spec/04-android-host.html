4. Android ホスト

MainActivity が受け持つ WebView の設定・読み込み・ライフサイクル・バックグラウンド再生。

4.1 起動の流れ

  1. dumpDebugLogIfAsked：起動の Intent に dumpDebugLog=true があればログを logcat に出す
  2. WebViewMissingActivity.webViewUsable：WebView が無い・古いときは案内の画面に切り替えて終わる
  3. AppLanguage.apply・applyOrientation：言語と画面の向きを合わせる
  4. AwakeWebView を作り、Bridge と ComposeView（NativeApp）を用意する
  5. 重ね順は WebView → ComposeView → 接続エラーの画面（loadError）
  6. SpotifyWebView.configure：JavaScript・DOM Storage・自動再生・デスクトップ UA・Client Hints・X-Requested-With の送信先を空に
  7. addWebMessageListener("AndroidBridge", open.spotify.com) と addDocumentStartJavaScript(polyfill.js)
  8. 最初の URL（共有された open.spotify.com のリンク、または https://open.spotify.com/）を読み込む
  9. bridge.ready を見て、ログインしていなければログインページへ、していれば音質・クロスフェード・ギャップレスを適用して画面を出す

4.2 WebView の設定

設定値・理由
User-AgentWindows のデスクトップ Chrome。モバイルだとアプリの案内に飛ばされる
Client Hintsデスクトップ Windows を名乗る。名乗らないと再生デバイスとして動かない
X-Requested-With送信先の許可リストを空にして付けない（対応している WebView のみ）
自動再生mediaPlaybackRequiresUserGesture = false
Cookie受け入れる（サードパーティも）。ログイン状態は Cookie で保つ
描画の優先度RENDERER_PRIORITY_IMPORTANT
デバッグデバッグビルド、または設定の webdebug が true のときだけ PC から調べられる

4.3 ページの読み込みとエラー

コールバック動き
shouldOverrideUrlLoadinghttp / https はそのまま WebView で開く。spotify:・intent: などの独自スキームは開けないので無視する
shouldInterceptRequest通信を記録する（DebugLog.traceRequest）。中身は変えない
onPageCommitVisible / onPageFinishedbridge.js を注入する（injectMobileUi）
onReceivedErrorメインフレームの失敗なら loadError を出す。再試行ボタンと、つながったときの自動再試行。失敗した URL を読み直す
onRenderProcessGoneWebView のプロセスが落ちたら Activity を作り直す

4.4 バックグラウンド再生

  • AwakeWebView は getWindowVisibility() を常に VISIBLE にし、裏に回ってもページを止めない
  • 再生が始まると PlaybackService（フォアグラウンドサービス、種類は mediaPlayback）を起動し、WakeLock と WifiLock を持つ
  • 一時停止してから 10 分たつとサービスを止める
  • 設定の「バックグラウンド再生」がオフなら、サービスは起動しない
  • イヤホンが抜けたとき（ACTION_AUDIO_BECOMING_NOISY）は一時停止する

4.5 通知とメディア操作

MediaControls が MediaSession と通知を持ちます。meta メッセージで曲名・アーティスト・アルバム・ジャケット・再生中か・位置・長さを受け取り、通知とロック画面を更新します。 ボタンの操作は Receiver（BroadcastReceiver）→ window.__mMedia の順に伝えます。

4.6 端末の状態の監視

対象用途
通信（ConnectivityManager）モバイルかどうかで音質を切り替える（applyQuality）。ページにも伝える
音声出力（AudioDeviceCallback）Bluetooth などの出力先の名前をミニプレーヤーに出す
画面の余白（WindowInsets）ステータスバー・ナビゲーションバーの高さ。edge-to-edge に対応する
設定の変更（onConfigurationChanged）言語の変更を受けて画面の文言を描き直す（Activity は作り直さない）

4.7 ログアウト

覚えておいたホーム・ユーザー名などのキャッシュ、デバッグログ、ページの保存データ（WebStorage）、Cookie を消し、Activity を作り直してログインページから始めます。

権限用途

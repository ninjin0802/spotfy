1. 概要

spotfy が何をするアプリか、だれのためのものか、何ができて何ができないか。

1.1 目的

Spotify の公式アプリに近い操作感で、Spotify Web Player の再生エンジンを Android から使えるようにすることが目的です。 特に無料プランで、広告の間の音を消して早く終わらせる、公式アプリに近い画面で操作できる、という体験を提供します。

1.2 対象

項目内容
対象の端末Android 8.0（API 26）以上。Android System WebView が動くこと
対象のアカウントSpotify の無料プラン・Premium（Premium 限定の機能は Web Player の範囲でのみ使える）
表示の言語日本語・英語（端末に合わせる／設定で固定）
配布GitHub Releases の APK（spotfy-<版>.apk）。Play ストアでは配布しない
パッケージ名com.ninjin.spotifyweb（表示名は spotfy）

1.3 機能一覧

分類機能
ホームすべて／音楽／ポッドキャスト（フォロー中）の切り替え、ショートカット、棚、最新リリース
検索ジャンルのタイル、最近の検索（保存・削除）、入力に合わせた結果、種類の絞り込み
ライブラリ絞り込み・並べ替え・リスト／グリッド、ピン、ライブラリ内検索、プレイリスト・フォルダの作成
ページアルバム・プレイリスト・アーティスト・ジャンル・プロフィールの表示
プレーヤーミニ／全画面プレーヤー（ジャケット色）、歌詞、アーティストについて、次に再生
キュードラッグでの並べ替え、外す、シャッフル、リピート、おやすみタイマー
再生ギャップレス再生、クロスフェード（1〜12 秒）、バックグラウンド再生、音質（Wi-Fi／モバイル別）
広告の処理Web Player の広告マネージャーの停止、広告中のミュートと 16 倍速、可能ならスキップ
キャストSpotify Connect で PC・スピーカー・TV へ、スマホのスピーカー／Bluetooth の切り替え
メニュー最近（再生したものを日ごとに）、あなたへのおすすめ新着、設定
ソーシャルプロフィールの編集、フォロワー／フォロー中、ほかのユーザーのフォロー
通知メディア通知（再生・一時停止・前後・シーク）、ロック画面の操作
設定テーマカラー 9 色、AMOLED ブラック、言語、デバッグログの共有、アップデート、このアプリについて
アップデートGitHub Releases の新しい版を知らせ、ダウンロードしてインストーラーに渡す

1.4 前提と制約

  • Spotify の公開 Web API（api.spotify.com）は使わない。このアプリのトークンでは回数制限（429）になるため、Web Player 自身が使う GraphQL・内部 API を同じ手段で呼ぶ
  • Web Player の内部の部品に依存するため、Spotify の更新で一部の機能が動かなくなることがある（健康診断で検知する）
  • Premium・公式アプリ専用の機能（ロスレス、Jam、ダウンロード、最高音質など）は使えない。Jam は Web Player 側でこのアカウントに配られていないことを確認済み
  • 無料プランの音質の上限は AAC 128 kbps（Web Player の制限）
  • 中継サーバーは持たない。通信は端末と Spotify・GitHub の間だけ

1.5 非機能要件

項目方針
起動約 2 秒で画面が出る（前回のホームなどを覚えておき、先に出す）
電池バックグラウンド再生中は CPU 1 コアの 45〜55% 程度（主に DRM の復号）。ページ自体は描かない
安定性WebView のプロセスが落ちても作り直す。通信エラーは自前の画面で知らせ、つながると自動で開き直す
保守性Spotify の更新で壊れた部品を健康診断とデバッグログで特定できるようにする

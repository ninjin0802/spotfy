spotfy 仕様書

非公式 Android アプリ spotfy（バージョン 2.4.2）の設計と仕様をまとめた文書です。章ごとにページを分けています。

この文書について

spotfy は、Spotify Web Player（open.spotify.com）を画面に出さない WebView で動かし、その上にアプリ独自のネイティブ UI（Jetpack Compose）を重ねて動く Android アプリです。 データの取得と再生（DRM を含む）は Web Player に任せ、画面・通知・設定・広告の処理・アップデートなどをアプリ側で受け持ちます。

この仕様書は、実装（main ブランチ）の内容をもとに書いています。コードと食い違う場合はコードが正です。

用語

用語意味
Web PlayerSpotify が提供するブラウザ版プレーヤー（open.spotify.com）。spotfy は画面に出さずに裏で動かす
ネイティブ UIアプリが Jetpack Compose で描く画面。Web Player のページの上に重ねて表示する
ブリッジアプリ（Kotlin）とページ（JavaScript）の間の通信の仕組み。Bridge.kt と bridge.js
登録簿（Registry）Web Player 内部のサービスの登録簿。PlayerAPI などの部品を名前で取り出せる
ConnectSpotify Connect。ほかの機器（PC・スピーカー・TV）での再生を操作する仕組み
健康診断起動後に、使っている Web Player の部品がそろっているかを確かめる処理（bhealth）

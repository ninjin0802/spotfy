## 画面の見かた

| 場所 | できること |
|:--|:--|
| **ホーム** | おすすめのプレイリストやアルバム。上の「すべて／音楽／ポッドキャスト」で切り替え |
| **検索** | 曲・アーティスト・アルバム・プレイリストを探す。ジャンルのタイルからも探せる |
| **ライブラリ** | お気に入りの曲、保存したプレイリストやアルバム。並べ替え・絞り込み・ピン留めができる |
| **ミニプレーヤー**（画面の下） | 再生中の曲。▶／⏸ で再生・一時停止、押すと全画面のプレーヤーが開く |
| **全画面のプレーヤー** | シーク、前後の曲、シャッフル・リピート、歌詞、次に再生（キュー）、おやすみタイマー |
| **🎧 のアイコン** | 再生する機器の切り替え（このスマホ・Bluetooth・PC・スピーカー・テレビなど） |
| **左上のアイコン** | メニュー（プロフィール・最近・あなたへのおすすめ新着・設定） |

## 設定

左上のアイコン → 「設定」で開きます。

### アカウント

| 項目 | 説明 |
|:--|:--|
| ユーザー名 | ログイン中の Spotify アカウント |
| ログアウト | このアプリからログアウトします。デバッグログも消えます |

### コンテンツと表示

| 項目 | 説明 |
|:--|:--|
| テーマカラー | ボタンや再生中の表示に使う色（9 色） |
| AMOLED ブラック | 背景を真っ黒にします。有機 EL の画面なら電池が少し長持ちします |

### 再生

| 項目 | 最初の設定 | 説明 |
|:--|:--|:--|
| バックグラウンド再生 | オン | アプリを閉じたり、ほかのアプリを使ったりしても再生を続けます。オフにすると、アプリを閉じたときに一時停止します |
| 広告をブロック | オン | 広告が流れたら音を消して、16 倍速で最後まで再生します（30 秒の広告が 2〜3 秒で終わります）。Spotify の利用規約に反する可能性があります |
| 起動時に再生の準備をする | オン | アプリを開いたとき、音を消して一瞬だけ再生して止めておきます。最初に ▶ を押したとき、すぐ鳴るようになります（約 1.2 秒 → 約 0.15 秒）。PC やスピーカーなど、ほかの機器で再生しているときは何もしません |
| ギャップレス再生 | オン | 曲と曲のあいだの無音を短くして、続けて再生します。下の「[ギャップレス再生とクロスフェード](#ギャップレス再生とクロスフェード)」も見てください |
| クロスフェード | オフ | 曲の終わりを少しずつ小さく、次の曲の始まりを少しずつ大きくしてつなぎます。オンにすると、秒数（1〜12 秒）を選べます |

#### ギャップレス再生とクロスフェード

曲が切り替わるところ（つなぎ目）の処理です。

```
ふつう        ♪♪♪♪♪♪ ……（無音）…… ♪♪♪♪♪♪
              今の曲                   次の曲

ギャップレス   ♪♪♪♪♪♪♪♪♪♪♪ ♪♪♪♪♪♪♪♪♪♪♪
              無音をできるだけ短くして、すぐ次の曲

クロスフェード ♪♪♪♪♪♪♪♪＼ ／♪♪♪♪♪♪♪♪♪♪
              今の曲の終わりを小さくしていき、次の曲の始まりを大きくしていく
```

- **ギャップレス再生**：曲間の無音をなくして、途切れずに次の曲へつなぎます。ライブ盤やつながっているアルバムを聞くときに便利です。
  - しくみ：曲の終わりが近づくと、次の曲を 2 台目の再生器で先に用意して、今の曲が終わる瞬間に鳴らし始めます。次の曲が始まって少したったら、いつもの再生器に音を戻します。
  - うまく用意できなかったときは、いつもの方法（ごく短い途切れが残ることがあります）で次の曲へ進みます。
- **クロスフェード**：つなぎ目の音量をなめらかに下げて上げるので、ラジオのように次の曲へ移ります。2 曲を実際に重ねて鳴らします。
  - 次の曲が鳴り始めたところで、ジャケットや曲名の表示も次の曲に切り替わります。
  - 秒数は、音量を下げて上げる長さです（半分ずつ、前の曲の終わりと次の曲の始まりにかけます）。長いほど、ゆっくり入れ替わります。
  - **おすすめは 5〜6 秒**です。

    | 秒数 | 感じ | 向いている聞き方 |
    |:--|:--|:--|
    | 1〜3 秒 | 曲間の無音がなくなる程度 | アルバムを通して聞く |
    | 5〜6 秒 | 自然に溶け込むように次の曲へ | プレイリスト全般 |
    | 8〜12 秒 | ゆっくり入れ替わる | 作業用 BGM |

  - ビシッと終わる曲が多いなら短め、ゆっくり消えていく曲が多いなら長めが合います。
- 両方オンでも大丈夫です。

### メディアの音質

| 項目 | 説明 |
|:--|:--|
| Wi-Fi でのストリーミング | Wi-Fi のときの音質 |
| モバイルデータ通信でのストリーミング | モバイルデータ通信のときの音質。低くすると通信量を節約できます |
| いまの状態 | 今の接続と、再生中の曲の実際の音質 |

| 音質 | 説明 |
|:--|:--|
| 自動 | 通信状況に合わせて調整 |
| 低音質 | 通信量を抑える |
| 標準 | 通信量を少し抑える |
| 高音質 | AAC 128 kbps（無料プランの上限） |
| 最高音質 | AAC 256 kbps（Spotify Premium のみ） |

### 言語

| 項目 | 説明 |
|:--|:--|
| 端末の設定に合わせる | 端末の言語が日本語なら日本語、それ以外は英語（最初の設定） |
| 日本語 ／ English | 端末の言語に関係なく、その言語で表示します。切り替えても再生は止まりません |

### アップデート

新しい版が出ていないか確かめます。新しい版があれば、ボタン 1 つでダウンロードしてインストールできます。
アプリを開いたときにも自動で確かめます（6 時間に 1 回まで）。

### デバッグログを共有

アプリの動きの記録（広告の処理、再生の操作、エラーなど）を共有します。
うまく動かないときに送ってもらえると、原因を調べられます。パスワードやログイン情報は入りません。

### このアプリについて

版の番号、作者、ソースコードやライセンスへのリンクです。

## よくある質問

<details>
<summary><b>アプリを開いてすぐ ▶ を押すと、鳴るまで少しかかる</b></summary>

アプリを開いた直後は、Spotify にこのスマホを「再生できる機器」として登録するのに数秒かかります。
登録が終わりしだい自動で鳴り始めるので、そのまま待ってください。「起動時に再生の準備をする」がオンなら、準備が終わったあとはすぐ鳴ります。

</details>

<details>
<summary><b>ほかの機器（PC・スピーカー）で再生しているのに、スマホで再生されてしまわない？</b></summary>

されません。「起動時に再生の準備をする」は、ほかの機器で再生しているときは何もしません。
スマホで鳴らしたいときは、🎧 のアイコンから「このスマホ」を選んでください。

</details>

<details>
<summary><b>「⚠ 一部の機能が使えません」と出る</b></summary>

Spotify 側の更新で、アプリが使っている部品が変わったのかもしれません。
その表示を押すとデバッグログを共有できるので、送ってもらえると直すのに役立ちます。

</details>

<details>
<summary><b>Premium の機能（ダウンロード・Jam など）は使える？</b></summary>

使えません。このアプリは Spotify Web Player を使っているので、Web Player でできることだけができます。

</details>
